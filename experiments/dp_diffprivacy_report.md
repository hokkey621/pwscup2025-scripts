# 差分プライバシー機構による匿名化実験まとめ

## 実験設定
- テンプレートを `experiments/dp_epsXX_*` として5件複製し、`config/params.json` 内の ε を変更。
- 数値列は `diffprivlib.mechanisms.LaplaceBoundedDomain` を用いて列ごとの範囲に合わせたラプラス機構を適用。カテゴリ列はεに基づくランダム化応答で置換、フラグ列は2値版を使用。
- 入力 Bi: `data/HI_10K.csv`、乱数シード 2025。`run_experiment.py` で Ci 生成→チェック→ Di 学習＆攻撃→ `evaluation/eval_all.py` を実施。
- 指標は `stats_diff_max_abs` / `lr_asthma_max_abs` / `KW_IND` (差分が小さいほど匿名性良好) と `Ci utility (/80)` (大きいほど有用性高い)。

## 所感
- ε=0.5 では強いノイズにより統計差分は最も小さいが、有用性スコアが 2.2 と極端に劣化。
- ε を 1〜2 に上げても統計差分は 0.95 付近からほとんど変化せず、`lr_asthma` 差分だけが僅かに改善。匿名性指標の頭打ちが観測される。
- 高ε(4〜8)では Ci utility が 3.6→5.9 と回復する一方、`lr_asthma` 差分は悪化し攻撃耐性が下がるため、実用上は ε≈2 が妥協点。
- 今後は列ごとに ε を割り当てたり、数値列のクリップ幅をさらに狭めて感度を縮めることで、より滑らかなトレードオフが得られる可能性がある。
